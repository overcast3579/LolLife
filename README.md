# LoLLife (英雄聯盟職業選手人生模擬器)

> 一款以台灣玩家為起點的《英雄聯盟》職業電競選手人生模擬網頁遊戲。
> 從 16 歲的天梯路人、網咖盃業餘賽出發，經歷戰隊試訓、LCP 晉升、賽區對決、旅外 LCK/LPL、征戰 MSI/世界大賽，直到功成名就或遺憾退役。

---

## ⚡ 遊戲特色

- **純前端、零依賴、無後端負擔**：使用現代 ES Modules 與純 CSS/JS 打造，開箱即玩，支援本機 LocalStorage 儲存及匯出/匯入存檔。
- **種子亂數確定性 (Seeded RNG)**：相同種子加上相同選擇，100% 產生完全重現的職業生涯。
- **8 維能力與動態成長衰退模型**：操作、對線、觀念、團戰、英雄池、心態、溝通、紀律，搭配五個位置專屬權重與 25 歲特異化衰退曲線。
- **真實賽事體系**：
  - 16 歲台灣天梯、六都/校園電競盃賽、戰隊試訓。
  - LCP 年度三 Split 循環賽制、季後賽與升降資格。
  - 頂級國際賽事：First Stand、MSI、世界大賽 (Worlds)。
  - 旅外轉會機制：前往南韓 LCK 或中國 LPL 挑戰更高殿堂。
- **7 階段事件式比賽與 BP 模擬**：
  - 第一階段 Ban/Pick 策略、自由選角（支援非主流奇招如索拉卡上路、李星輔助）。
  - 從一級團入侵、對線換血、首輪物件、鍍層推進、中期營運、巴龍逼團到終局遠古巨龍決策。
- **40+ 寫實事件卡與 20 種特質**：涵蓋訓練衝分、隊友衝突、健康傷病（手腕/腰背/睡眠）、公關採訪、人生學業抉擇。
- **退役評價與生涯分享卡**：全面評定歷史定位（高端路人 ~ 歷史最佳 GOAT），並生成高質感電競分享年表卡。

## 🎮 快速開始

### 本機開啟
直接在瀏覽器中開啟 `index.html`，或使用任何靜態網頁伺服器（例如 VS Code Live Server 或 Python 內建伺服器）：

```bash
# 使用 Python 快速預覽
python -m http.server 8080
# 瀏覽器訪問 http://localhost:8080
```

## 📁 專案架構

```
lolLife/
├── index.html               # 遊戲主入口
├── css/
│   ├── main.css             # 電競暗黑轉播風格 HUD、排版與微動畫
│   └── themes.css           # 賽區主題色彩 (LCP / LCK / LPL)
├── data/
│   ├── champions.js         # 全英雄屬性、特性標籤與傷害類型
│   ├── teams.js             # 賽區戰隊庫與選手生成
│   ├── leagues.js           # 聯賽與國際賽制設定
│   ├── events.js            # 40+ 寫實事件庫
│   ├── traits.js            # 隱藏與顯性特質資料庫
│   └── meta.js              # 動態版本 Meta 生成器
├── js/
│   ├── rng.js               # 種子亂數引擎 (Mulberry32)
│   ├── state.js             # 全域狀態與存檔管理
│   ├── player.js            # 選手能力、潛力、年齡曲線與健康模型
│   ├── champions.js         # 英雄熟練度與陣容適性
│   ├── career.js            # 16-17 歲業餘與試訓流程
│   ├── season.js            # 職業年度循環、常規賽與季後賽
│   ├── match.js             # BP 選角與 7 階段賽事模擬引擎
│   ├── contracts.js         # 轉會市場與合約談判
│   ├── eventsEngine.js      # 事件判定與決策分歧
│   ├── retirement.js        # 退休結算與分享卡產生器
│   ├── ui.js                # UI 渲染與 HUD 互動
│   └── app.js               # 遊戲主流程驅動
├── tests/
│   └── sim_test.js          # 自動化平衡與種子驗證測試
├── 規劃.md                   # 完整設計規劃說明書
└── README.md
```
